# S7 飞书回复模板

按固定顺序渲染，所有事实必须来自 runtime 的确定性 `competitor_context`：

1. 数据状态、业务日和抓取时间。
2. 结论边界：四级可比合同；没有精确商品时禁止房型价差。
3. 按平台展示：同行聚合、自有商品、活动/权益、评分/排名、月度流失背景；美团另展示按 `competitor_circle_name` 聚合的竞争圈。
4. 数据质量与行动限制：`source_missing`、`mapping_missing` 等质量标记；S7 不创建任务。

同行聚合必须显示 metric code、本店值、同行均值、单位、业务日或窗口及来源排名/人口。评分排名逐项显示，不合成为综合名次。禁止输出未被数据直接支持的“房型比竞店贵/便宜”“流量领先”“排名靠前/靠后”等结论。
