# S15 销售基准线

> capability_id：`sales_baseline`  
> 当前 service：`s15_sales_baseline`  
> 能力名称、目录名、capability ID 和 node ID 保持不变。  
> 算法依据：`Digital-Employee-Algorithm-Technical-Spec-2026-07-08.md`。

## 1. 业务职责

S15 负责生成完整、可信、可核查的基准数据包：

- 全店最终销售目标；
- 房型最终销售目标；
- 全店小时销售基准；
- 房型小时销售基准；
- 估算大盘订单基准；
- 估算市场份额基准；
- 浏览基准；
- 一转基准；
- 二转基准；
- 房型实际成交参考；
- 同一 OTA 商品的历史价格基准；
- 引流价与排名基准；
- 每条基准的样本数、成熟度、时间范围、数据缺口和可比性。

S15 可以说明一条基准是否成熟、是否可比较、能否供下游使用，但不负责：

- 当前小时经营原因的跨基准归因；
- 主要原因、次要原因排序；
- 调价、推广、活动或尾房动作；
- 动作观察期、冷却期或自动执行资格；
- 声称任何动作已执行。

当日动态原因解释由 S16 进度偏差诊断完成。S14 可以在独立静态复盘场景中读取 S15，但 S15 不依赖 S14。

## 2. 缓存规则

S15 基准数据包优先读取控制面 SQLite `baselines` 物化结果，不使用散落的本地 JSON 作为生产事实源。

缓存按以下范围隔离：

```text
hotel_id
target_business_date
baseline_package_version
历史数据截止日
日历/节假日规则
启用渠道配置
```

同一酒店和目标日期在缓存有效时直接复用；缓存缺失、损坏、版本不兼容或历史截止日变化时才重建。

S15 缓存不得包含：

- 当前销售快照；
- 当前大盘、浏览、一转和二转状态；
- 当前商品价格结论；
- 动态归因；
- 动作候选。

## 3. 基准计算边界

### 销售基准

使用真实历史同类日期和真实小时采集点。缺少某小时样本时显示缺口，不使用默认曲线冒充真实基准。

每个全店和房型基准至少提供：

```text
最终参考销售间夜
小时容量消化 P20/中位/P80
小时最终目标完成 P20/中位/P80
样本日期
样本数
成熟度
数据覆盖
```

### 平台基准

`meituan_ota_business_metrics` 为日级数据时：

- 浏览、一转、二转、大盘、份额、引流价和排名只建立日级基准；
- 不声称存在小时平台基准；
- 当前日内累计不在 S15 中与历史完整日做动态强弱判断。

### 大盘和份额

平台没有直接竞争圈订单时，可以按经验证的同行均值和同行范围建立估算基准，但必须始终称为“估算大盘订单”和“估算市场份额”。

### 价格

PMS `rs01_room_revenue_daily` 只生成“房型实际成交参考”，可以展示 P20、中位、P80 和样本间夜。

OTA 商品价格高低只有在同一：

- 酒店；
- 平台；
- `ota_product_id`；
- 商品类型；
- 目标入住日或可比窗口；
- 入住人数、间数和晚数；
- 套餐、取消、税费和优惠口径；

具备连续历史价格时才能建立。

没有合格商品历史时，只输出：

> 暂无同一商品的可比历史价格。

不得用 PMS 房型实际成交价证明 OTA 商品挂牌价偏高或偏低。

## 4. 渠道和酒店范围

所有数据先按真实 `hotel_id` 和启用渠道过滤。没有匹配到当前酒店的渠道数据时自然不进入基准，也不在普通回复中显示“整组禁用”、映射状态或其他工程术语。

用户明确询问携程且当前携程数据主体与酒店不一致时，只说明：

> 当前携程数据主体与本酒店不一致，本次未纳入分析。

## 5. 输出规则

普通飞书输出只展示：

1. 最终销售目标；
2. 关键小时销售基准；
3. 平台历史基准；
4. 房型实际成交参考和商品历史可用性；
5. 样本、成熟度和数据边界。

禁止输出当前动态归因和动作建议。

禁止显示：

```text
M4_same_weekday_daily
WEAK_REFERENCE
period_mismatch
canonical
metric code
patch version
internal status key
```

统一翻译成业务中文，例如：

> 历史共 21 天，本次选取 3 个同星期几样本。样本较少，目前仅供趋势观察，不作为自动动作依据。

## 6. AI 边界

AI 只可以解释每条基准回答什么问题，并将确定性结果组织为可读中文。

AI 不得：

- 修改任何数字；
- 重算阈值和分位数；
- 将不可比数据说成可比；
- 将弱样本说成稳定结论；
- 生成调价或推广动作；
- 声称已执行任何写操作。
