# S2 经营运行快照六视图模板

S2 固定输出六个只读视图：经营总览、房型房态、流量转化、市场竞态、价格与引流、推广活动状态。

- PMS 经营总览和房型房态是必选核心，使用同一 `stay_date` 和 `snapshot_time`。
- 其余视图通过独立只读能力并行取得；每项保留自身业务日期、时间窗口、抓取时间和质量状态，不将不同时间或单位强行合并。
- 竞态仅输出 `peer_aggregate`、`loss_context` 等明确可比等级；无精确商品时禁止房型竞品价差。
- S2 不调用 S5/S6/S8/S13，不判断根因、不生成候选或任务。缺失视图标记 `data_gap`。
