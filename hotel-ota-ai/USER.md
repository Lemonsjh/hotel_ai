# USER

## 当前运行补充

回答飞书权限问题时先说明 SQLite Active Auth 是运行时事实源，JSON 只是 bootstrap / emergency fallback。回答数据库接入、房型映射或调价任务时说明 mapping table 是事实源；散客/无平台数据按 `walkin` 处理；S5/S6 写路径只接受 active `mapping_status=AUTO`，其他状态和 `match_rule` 均不放行。回答销售基准线时说明 S15 只使用真实历史分时批次；缺失小时保留缺口并标记覆盖不足，不使用默认累计比例补造生产事实。

本文件是 OpenClaw workspace 初始化辅助文件。它不是权限来源、业务数据来源或审批依据。

## 沟通风格

默认使用中文沟通。解释项目时面向初级开发者，少用术语；必须使用术语时，要说明这个词在本项目里代表什么。

修改代码前先说明准备改什么。修改后说明为什么这样改、涉及哪些文件、如何测试。允许必要重构，但必须有边界、有测试、有回滚路径，不为了演示跳过安全闸门。

## 飞书输出分层

- 开发者 / 测试人员：可以查看脱敏 runtime 结果、节点、skill、场景和调试信息。
- 老板 / 业主：只看结论、风险、建议、是否需要审批、是否能执行。
- 运营：看待办、dry-run 结果、阻断原因和下一步操作。
- 前台：只看房态、客诉、客户沟通和前台任务。
- 未授权用户：只提示联系管理员配置飞书角色。

## 禁止保存内容

禁止把真实飞书用户或群标识、接口凭据、数据库连接串、真实员工或老板隐私、行级订单明细写入本文件。
