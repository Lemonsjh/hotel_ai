# 酒店数字员工｜生产能力菜单

> 本文件是生产飞书“菜单 / 能力菜单”的唯一菜单事实源。菜单只展示可用入口，不读取经营数据。
>
> 编号 `5` 已停用且不再复用；不得根据旧 Skill 列表、Scenario、历史文档或模型记忆重新补出第 5 项。

🏨 **酒店数字员工｜能力菜单**

经营分析・OTA 运营・收益调价・推广口碑・酒店管理

发送编号或能力关键词即可；编号可一次发送 1–3 个，例如「1 3 6」。

## 📊 经营与销售

1｜经营快照 / 日报：实时出租率、已售间夜、ADR、RevPAR；发送「今日日报」「昨日日报」「生成今日经营日报」「生成昨日经营日报」均只进入 S2，不拼装其他 Skill 综合诊断

2｜销售基准线：今日目标、小时目标、目标曲线

3｜进度诊断：当前完成率、节点偏差、剩余缺口、分时销售；当日浏览、一转、二转问题也由这里解释

4｜环境行情：业务日历、节假日、天气、周边活动、市场热度

## 📣 OTA 运营与口碑

6｜竞对监控：竞品价格、排名、同行指标与市场变化

7｜口碑评价：评价概览、风险评价、待处理评论

8｜评论回复：生成或编辑回复草稿、确认提交、查看任务状态

## 💰 收益、调价与推广

9｜收益建议：价格方向、建议价格、证据与风险说明

10｜调价 dry-run：按房型和 OTA 商品预览价格、护栏与执行条件

11｜推广数据：推广通曝光、点击、订单、花费与近 30 天表现；只展示真实数据，不生成投放方案

12｜推广 ROI：投入、产出、订单与转化效果分析，判断推广是否值得继续

13｜流量转化专项：完整漏斗、美团/携程转化对比、近 30 天流量转化分析

14｜客户订单分析：渠道、客群、房型与订单结构

## 🧭 角色视图与运行

15｜运行状态：当前数据源、运行模式、数据日期与安全开关

- 老板视角｜发送「老板视角」
- 运营视角｜发送「运营视角」
- 前台任务｜发送「今日前台任务」
- 健康检查｜发送「健康检查」
- 安全自检｜发送「自检」

## ⚙️ 执行预览与经验沉淀

- 推广执行 dry-run｜发送「推广执行」
- 经验候选｜发送「经验候选」；候选需人工审核，不直接修改生产规则

## 👤 身份、会话与角色

- 身份与权限｜发送「我的身份」或「当前群成员角色」
- 鉴权路径｜发送「鉴权路径」
- 查看绑定｜发送「查看当前会话绑定」
- 申请绑定｜发送「绑定当前群到酒店 hotel_id」或「绑定当前私聊到酒店 hotel_id」
- 申请解绑｜发送「解绑当前会话」
- 加入酒店｜发送「申请加入酒店」或「申请成为前台」
- 角色变更｜发送「将某人设为运营」或「将某人设为前台」
- 确认或取消｜发送「确认 BIND-*」「取消 BIND-*」「确认 ROLE-*」或「取消 ROLE-*」

## 🛡️ 价格、商品与配置

- 价格护栏｜发送「价格护栏状态」
- 护栏变更｜提供房型、底价、顶价、最小涨跌幅和最大涨跌幅
- 可调价商品｜发送「美团可调价商品」或「携程可调价商品」
- 待处理申请｜发送「待处理配置申请」
- 配置审计｜发送「配置审计摘要」
- 确认或取消｜发送「确认 CFG-*」或「取消 CFG-*」

## 🔒 使用边界

- 生产飞书不回退 demo、sample 或 synthetic 数据；缺数据时返回 `data_gap`、`stale` 或 `schema_drift`
- 调价、推广执行、评论回复提交、角色与配置变更均需满足真实数据、新鲜度、权限、护栏及确认流程
- 状态菜单只负责选择编号；选中后必须重新进入与直接发送该编号相同的 Router / Skill / renderer 链路，菜单层不得重算、裁剪或改写 Skill 输出
- 菜单不展示开发调试、造数或被安全策略拒绝的入口
- 第三方 OTA HTML 诊断报告已经迁移到独立服务，本项目普通菜单不再提供该能力
