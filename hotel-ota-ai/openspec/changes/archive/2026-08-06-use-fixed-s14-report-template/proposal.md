# use-fixed-s14-report-template

## 背景

S14 当前本地报告由 `runtime/s14_operation_diagnosis.py` 手写简化 HTML，并以 `s14-{uuid}.html` 生成随机文件名。飞书实测需要对齐用户提供的固定报告模板体验（示例模板由运维单独提供，不入库），并使用固定文件名 `ota_diagnosis_report.html`，方便 OpenClaw/飞书入口稳定引用。

## 目标

- S14 本地报告使用固定文件名 `ota_diagnosis_report.html`。
- 报告 HTML 结构参考示例模板，保留总览、模块得分、风险、缺失字段和建议动作等现有数据/计算输出。
- 模板可按当前 runtime 的可用聚合数据微调，不要求复制示例中的静态演示数据。
- 报告继续只展示聚合诊断结果，不包含敏感字段、DSN、本地私有路径或 live 执行结果。

## 非目标

- 不改变 S14 诊断分数、模块权重和字段覆盖率计算逻辑。
- 不新增数据库写入、删除或外部发布能力。
- 不把示例模板中的演示渠道数据硬编码进生产报告。
